# 100_days_of_Python
## Follows the course 100 days of Code - Python

- **Day 1:** Working with variables in Python to manage data.  
  **Task:** Create a script that takes three inputs from the user and generate a band name.

- **Day 2:** Understanding data types and how to manipulate strings.  
  **Task:** Create a script that calculates the tip and total bill from three inputs from the user, bill, percentage, and how many people to split the bill.

- **Day 3:** Control flow and logical operators.  
  **Task:** Create a script using conditionals and inputs a short small adventure game.

- **Day 4:** Randomisation and Python Lists.  
  **Task:** Create a script to play rock, paper and scissors, using randomisation and python list.
